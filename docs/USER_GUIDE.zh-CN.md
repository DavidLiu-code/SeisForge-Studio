# SeisForge Studio 1.9.15 用户指南

SeisForge Studio 用于在 Windows x64 上浏览、质检和分析 SEG-Y。程序不会修改正在查看的源文件；只有用户明确执行导出时才创建新文件。

## 1. 首页与打开数据

首页提供三个明确入口：

- **二维剖面**：打开普通二维或规则数据的 Inline、Crossline、Time Slice 工作区。
- **三维数据体**：直接进入规则三维体窗口，不经过二维剖面。
- **弯曲测线**：先进入空白弯线工作区，再选择单个/多个 SEG-Y 或文件夹。

也可以把 `.sgy` / `.segy` 拖到首页。Recent 会记住最近文件、弯线文件集合或文件夹项目。显式选择的工作区优先，程序不会把用户指定的三维入口自动改成二维。

首次打开规则三维或弯线项目时，程序可能扫描道头并建立索引。此过程只读取必要元数据，进度和错误显示在当前工作区；异步识别失败不会悄悄跳转到另一个工作区。

## 2. 普通二维剖面

### 浏览

1. 在“方向”选择 `Inline`、`Crossline` 或 `Time Slice`。
2. 使用前后按钮、滑块或坐标输入框切换当前位置。
3. `自动识别` 从道头估计 Inline/Crossline 字节；方向名称相反时使用 `IL/XL交换`。
4. 左键拖出矩形以放大；双击剖面在最近一次放大范围和前一视图之间切换。
5. `还原` 返回当前数据加载范围。

Time Slice 需要可用的规则 IL/XL 几何。对于无法可靠识别的文件，应先检查道头字节设置，不要仅凭画面猜测方向。

### A/B、差值与频谱

- `比`：加载或显示 B 数据。拖入第二个文件也可作为 B。
- `差`：显示 A-B；程序按当前几何坐标匹配实际道。
- `谱`：计算当前可见范围的平均振幅频谱。
- `十字联动`：在 A、B 和差值面板间同步当前位置。
- `矩形`、`椭圆`、`线段`：添加屏幕标注；`清除标注` 删除当前标注。

色标和增益是显示参数，不改变源振幅。快捷键见[快捷键表](SHORTCUTS.md)。

### 单道查看

点击工具栏的 `道` 进入持续选道模式，再单击任一剖面：

- A 面分析 A 的物理道，B 面分析 B 的物理道。
- 差值面同时载入匹配的 A/B 道；采样间隔一致时附加 A-B 波形与频谱。
- Inline/Crossline 按最近实际几何道选择；Time Slice 按点击的 IL/XL 查找真实道。

可以连续点击不同位置刷新同一分析窗口。再次点击 `道`、按 `Esc` 或切换到其他绘图工具可退出。

## 3. 二维叠后弯线

### 建立项目

进入弯线工作区后可：

- `打开文件`：选择一个或多个 SEG-Y；单文件自动包装为单线项目。
- `打开文件夹`：只扫描文件夹当前层的 `.sgy` / `.segy`，不递归子目录。
- 拖放一个文件夹或多个 SEG-Y。

程序按自然线名排序。若目录中存在可解析的 `.dat` 导航文件，会选择与 SEG-Y 线名匹配最多的导航；最终 Geometry、命中和伪三维仍以经校准的逐道 SEG-Y 坐标为准。损坏线在列表中显示错误，不阻断其他有效线。

### 坐标识别

默认自动候选顺序为：

1. Ensemble X/Y：字节 181/185。
2. Source X/Y：字节 73/77。
3. Group X/Y：字节 81/85。

默认 CDP、坐标比例因子和坐标单位字节分别为 21、71、89。所有输入均使用 SEG-Y 1-based 字节位置。自动结果不正确时，打开 `道头设置` 修改 X、Y、CDP、比例因子和单位字节，再“应用并重建”。

比例因子按 SEG-Y 规则解释：正值相乘、负值相除、零按 1。导航校准只作用于显示副本，不写回 SEG-Y 或 `.cidx`。

### Geometry 与剖面

- 上方 Geometry 显示项目轨迹，右侧列表切换活动线，下方只显示活动线剖面。
- 单击轨迹选择最近测线/道；拖动矩形放大 Geometry；双击 Geometry 恢复全区。
- 下方剖面左键拖动平移，滚轮以鼠标位置为中心缩放，`剖面复位` 恢复完整范围。
- 横轴可选 `Trace`、`CDP` 或 `Distance`。Distance 使用累计坐标距离；角度坐标不会自动投影成米。
- `道` 只作用于下方剖面，可打开单道分析。

四种风格为 `干净 / CIGVis / 解释 / 标准`。风格与伪三维同步；干净模式隐藏辅助网格、标签和动态高亮，但操作中的选择框仍临时可见。

### 伪三维范围

- `范围`：在 Geometry 中拖动蓝色矩形，设置伪三维 XY AOI；下方二维剖面不裁剪。
- `清除范围`：恢复全项目伪三维候选。
- `时间范围`：在下方完整剖面中垂直拖动统一毫秒窗。
- `清除时间`：恢复完整记录时间。
- `Esc`：取消正在进行的范围选择。

完全位于 AOI 或时间窗外的测线不会进入振幅读取队列。穿越边界的测线只生成框内连续幕布段。

## 4. 伪三维幕布

点击弯线工具栏的 `伪` 打开非模态窗口。伪三维沿校准后的真实 XY 轨迹竖立各线的时间剖面，不在测线之间插值，也不生成体素体。

### 测线和进度

- 有效且在范围内的测线默认勾选；复选框控制显示，列表焦点控制活动高亮。
- `全选`、`清空`、`仅当前线`可快速调整场景。
- 加载状态依次显示准备、读取/解码、预览、最终渲染和明确的“完成 N/N”；部分失败时保留成功/失败数量。
- 修改 AOI 时优先复用已有纹理并即时预览，仅为新增或边界部分补载。

### 联动和范围调整

- 在弯线二维移动道/时间光标，伪三维会显示对应幕布位置；光标位于范围外时只提示，不自动扩大范围。
- 双击已显示幕布可返回对应二维线、道和时间；双击空白不会切换窗口。
- `Ctrl+拖动` XY 外框边或角调整空间范围。
- `Ctrl+拖动`时间起止面中央调整时间窗；拖动只预览，松开后提交。

### 导出范围

`导出范围`只在至少设置了 XY AOI 或时间窗，且存在已勾选、已完成显示的测线时启用。每条线导出为独立 SEG-Y，并生成 JSON 清单；相机旋转、缩放、遮挡和屏幕视锥不属于导出范围。

导出在后台运行，可取消。已完整提交的文件保留，当前未完成临时文件会清理；单线失败不会阻断其余线。

## 5. 规则三维体

### 加载和索引

三维入口创建独立窗口，并在后台执行：打开文件、识别几何、建立/读取 `.lidx`、加载首个切片。右侧进度条和状态文字显示当前阶段；缓存命中时可能快速跳到完成。

若 IL/XL 不正确，可用 `识别` 重新检测或在二维工作区检查 IL/XL 字节并交换方向。

### 三切片浏览

- 顶部 IL、XL、T 控件改变三张正交切片的位置。
- 三张切片使用同一 `MapMin/MapMax`，使相同色标值在三个方向代表相同振幅。
- `clip 99%` 会抑制孤立极端填充值对共享范围的控制；零仍作为合法振幅参与统计。
- `平铺`在三维和三面平铺视图之间切换。
- 双击某一切片进入该切片的 2D Full View；按 `Esc` 返回三维。
- 在 2D Full View 中启用 `道`，单击可分析对应真实 IL/XL/样点位置的物理道。

`比`加载 B；左右体可以独立浏览，`与左图一致`同步 B 到 A 的位置和相机。`差`增加 A-B 三维残差视图。`出`按自定义 IL/XL/Time 范围导出 A、B 或 A-B 子体。

完整相机和键盘操作见[快捷键表](SHORTCUTS.md)。

## 6. SEG-Y 文件与单道分析

分析窗口为只读、非模态窗口，可以保持打开并连续接收新的选道结果。

### 卷头

- `文本卷头`显示主文本卷头和正计数扩展文本卷头，可在自动、ASCII、EBCDIC CP037 间切换解码。
- `二进制卷头`显示文件摘要和 400 字节字段表。
- Hex 默认收起，可展开查看完整原始字节。

### 道头

- 道号在界面中为 1-based，可转到、上一道或下一道。
- 表格列为“字节位置（1-based）/ 字段 / 原始值 / 解释值”。
- 筛选可选 `全部 / 关键 / 非零`；“非零”只按原始整数是否为零判断。
- 顶部固定显示来源、几何摘要、样点数/间隔一致性和警告。

### 单道分析

- 波形采用时间向下、振幅横向，并用每像素包络保留尖峰。
- 可分析当前二维可见时间窗或完整道。
- 视觉范围可选 99% 自适应或全振幅；统计始终来自原始样点。
- 统计包括 Min、Max、Mean、RMS、标准差、绝对峰值、零值、NaN/Inf 和有效样点数。
- 频谱使用去均值、Hann 窗和零填充，显示完整 Nyquist 范围、归一化 dB、主频与 NFFT。

`复制当前页`生成带列头 TSV，可粘贴到 Excel，并包含当前摘要、警告、筛选字段和完整 Hex。分析窗口本身获得键盘输入时可按 `Esc` 关闭；焦点位于标准子控件时可使用“关闭”按钮。

## 7. 常见问题

### 三维切片接近全黑

先确认使用 1.9.11 或更新版本。当前版本会在三张切片上共享归一化，并用 99% clip 抑制孤立填充值。若启用了手动 Min/Max，先恢复自动范围再判断。

### 弯线没有轨迹或位置错误

检查道头设置中的 X/Y、CDP、比例因子和单位字节；确认坐标不是全零且至少存在多个不同位置。若使用导航文件，还应确认线名可与 SEG-Y 文件名匹配。

### 首次打开较慢

首次规则三维或弯线项目需要建立几何索引；伪三维首次显示还需生成纹理。后续打开会复用 `.lidx`、`.cidx` 和 `.ptx`。移动或修改源文件会使对应缓存失效，这是正常行为。

### 需要提交问题

在 GitHub Issue 中提供版本、工作区、操作步骤、预期结果和截图。若必须提供数据，请构造可复现的最小脱敏 SEG-Y，不要上传客户坐标、测线名或完整生产数据。
