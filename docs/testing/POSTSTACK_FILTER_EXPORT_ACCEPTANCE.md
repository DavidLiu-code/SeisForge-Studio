# 叠后滤波、SNR 与数值导出验收

以下是历史合成回归记录，不代表新发布构建的桌面验收。

## 道数与时间轴

合成规则夹具的完整范围为 2273 道 × 351 样点，时间范围 800–1500 ms，采样间隔 2 ms。Crossline 1120–1322 含首尾共 203 道。

另发现独立缺陷：旧时间剖面从几何密集格网取数时，同一格点只能返回一个道，可能在滤波输入／导出选择时丢掉重复几何号对应的物理道。数值路径现使用全部真实物理道，显示路径仍保持原渲染语义；外部 A/B 的重复几何若无法唯一配对，不凭顺序伪造差值。

| 环节 | 合成规则完整剖面 | 合成指定裁剪 |
| --- | --- | --- |
| 道与样点 | 2273 × 351（XL 184–2456） | 203 × 46（XL 1120–1322） |
| 样点时间 | 800–1500 ms，dt 2 ms | 1086–1176 ms，dt 2 ms |
| 处理与重读 | 处理输入、滤波 B、导出重开保持全部道与顺序，含零道 | 导出重开与已生成结果的真实索引子集一致 |

## 验证

- 自动：`go test ./... -count=1`、`git diff --check`、Windows 测试 EXE 和 GUI EXE。SNR 使用共同有效时域能量，覆盖相等、半幅、零参考/误差、缺测与局部 B；对照同一单道与主统计。覆盖共享实际刻度、整数 ms、正 dB、四类 IIR 算法与响应、短记录拒绝、维度与头字段、重复几何、局部交集、仅裁已提交视图、不覆盖和取消。
- Windows 实测：用合成 A 实际运行公开逐道时间滤波、生成正式 B，检查 A/B/差对齐。20–162.5 Hz 在 dt=2 ms 时合法，响应覆盖至 250 Hz。频谱只选 B 时，A 保持基准；恢复 B 回到其正式结果。主信息显示 8 道、2808 个共同有效样点及 14.26 dB；单道实际显示 800–1500 ms 和 0、25、50、75、100、125 Hz。新对话框内选 A−B，实际写出并重新打开校验 8×351。
- 未逐项用 GUI 验证所有高 DPI、所有范围/设计组合及取消时序；这些项目有相应自动测试。系统文件框的自动化焦点不可靠，独立加载外部合成 B 未在本轮 GUI 重测，桌面验收使用正式生成 B。未运行外部生产算法。
