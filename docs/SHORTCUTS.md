# 快捷键与鼠标操作

本表对应 SeisForge Studio 1.9.15。快捷键只在相应窗口处于活动状态时生效。

## 普通二维

| 输入 | 功能 |
| --- | --- |
| `Q` / `W` | 显示增益 +1% / -1% |
| `E` / `R` | 下一 / 上一色标 |
| 左键拖动 | 默认模式下框选同步放大 A/B/差值；标注模式下绘制当前标注 |
| 双击剖面 | 已有有效放大时，在放大前/放大后视图间切换 |
| 悬停 | “十字联动”启用时同步 A/B/差值位置 |
| `道`模式单击 | 选择真实 SEG-Y 道并打开或刷新分析窗口 |
| `Esc` | 退出`道`模式，恢复拖动缩放 |

普通二维画布没有自定义滚轮或右键手势。

## 二维叠后弯线

| 区域与输入 | 功能 |
| --- | --- |
| Geometry 悬停 | 高亮鼠标附近的测线 |
| Geometry 单击 | 选择最近测线和道 |
| Geometry 左键拖动 | 超过约 5×5 像素后框选放大总图 |
| Geometry 双击 | 恢复完整项目范围，不修改伪三维 AOI |
| 剖面悬停/单击 | 更新时间和当前道光标 |
| 剖面水平左拖 | 平移当前可见道范围 |
| 剖面滚轮 | 以鼠标横向位置为锚点缩放 |
| `范围`模式拖动 Geometry | 设置伪三维 XY AOI |
| `时间范围`模式垂直拖动剖面 | 设置伪三维时间窗 |
| `道`模式单击剖面 | 打开或刷新单道分析 |
| `Esc` | 退出`道`模式，或取消当前范围/时间/Geometry 框选 |

弯线二维没有 `Ctrl`、`Shift`、右键或 Q/W/E/R 专用操作。

## 真三维

键盘快捷键在真正的三维场景中生效；2D Full View 仍可使用 Q/W/E 调整显示。

| 输入 | 功能 |
| --- | --- |
| `X` / `Shift+X` | 增大 / 减小 Inline 轴倍率（0.10×–8.00×） |
| `Y` / `Shift+Y` | 增大 / 减小 Crossline 轴倍率 |
| `Z` / `Shift+Z` | 增大 / 减小 Time 轴倍率 |
| `R` / `Shift+R` | 整体放大 / 缩小三维体 |
| `F` / `Shift+F` | 增大 / 减小 FOV；0° 为正交投影 |
| `Q` / `W` | 三切片显示增益 +1% / -1% |
| `E` / `Shift+E` | 下一 / 上一色标 |
| `A` | 在状态栏显示 Camera、Pan、Zoom、FOV 和轴倍率 |
| `D` | 开关 Drag Mode；开启后普通左拖直接移动切片 |
| `Space` | 恢复保存的默认相机姿态、Zoom、Pan 和 FOV |
| `Esc` | 在 2D Full View 中先退出`道`模式，再按一次返回三维 |

| 鼠标输入 | 功能 |
| --- | --- |
| 左键拖动 | 旋转相机 |
| `Shift+左拖` | 平移相机 |
| `Ctrl+左拖` | 拖动命中的 Inline/Crossline/Time 切片 |
| 右键上下拖 / 滚轮 | 缩放三维体 |
| 单击切面 | 选择活动切面，不改变三维交点 |
| 双击切片 | 打开该切片的 2D Full View，不改变三维交点 |
| `Ctrl+双击`切片 | 在点击处重定位 IL/XL/Time 交点并留在三维 |
| Full View 双击 | 返回三维 |
| Full View 的`道`模式单击 | 选择对应物理 SEG-Y 道 |

轴倍率、风格和其他视图参数不一定随 `Space` 一并恢复；以“设为默认”保存的相机字段为准。

## 伪三维

| 输入 | 功能 |
| --- | --- |
| `X/Y/Z`，配合 `Shift` | 分别增大 / 减小 X、Y、Time 轴倍率 |
| `R` / `Shift+R` | 整体放大 / 缩小 |
| `F` / `Shift+F` | 增大 / 减小 FOV |
| `Q` / `W` | 显示增益 +1% / -1%，并同步弯线项目显示参数 |
| `E` / `Shift+E` | 下一 / 上一色标 |
| `A` | 在状态栏显示 Camera 与 Axis 参数 |
| `Space` | 恢复保存的默认相机姿态、Zoom、Pan 和 FOV |
| `D` | 不移动切片，仅提示伪三维没有正交切片 |
| `Esc` | 取消正在进行的 XY 或时间范围拖动 |

| 鼠标输入 | 功能 |
| --- | --- |
| 左键拖动 | 旋转相机 |
| `Shift+左拖` | 平移相机 |
| 右键上下拖 / 滚轮 | 缩放 |
| 悬停幕布 | 高亮幕布并显示线名、Trace、CDP、XY 和时间 |
| 双击幕布 | 返回对应弯线二维测线、真实道和时间 |
| `Ctrl+左拖` XY 外框边/角 | 调整伪三维 XY AOI |
| `Ctrl+左拖`时间起止面中央 | 调整伪三维时间窗 |
| 列表复选框 | 显示或隐藏测线 |
| 单击列表行 | 设置活动高亮测线，不等同于勾选状态 |

伪三维没有直接的单道分析模式；双击幕布返回弯线二维后使用`道`。

## SEG-Y 分析与对话框

- SEG-Y 分析主要使用来源、道号、上一道/下一道、转到、样点窗、振幅尺度、页签、筛选、Hex 和复制控件。
- 分析父窗口收到 `Esc` 时会关闭；若键盘焦点停留在某个标准子控件，可直接使用“关闭”按钮。
- 数据加载、参数和导出对话框支持界面中的“确定/取消”；三维导出数字输入兼容 NumPad。
