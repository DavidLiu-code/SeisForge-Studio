# SeisForge Studio v1.10.4

SeisForge Studio v1.10.4 是叠前只读 A/B Compare 的正式稳定版。

## 主要内容

- 叠前 A、B 使用独立 Dataset、Reader、道头映射、索引、取消函数和代次。
- 通过 Source/Receiver ID、缩放后的 XY、CDP 与有符号 Offset 进行可审计匹配，保持 A 道集顺序。
- A、B、差（A-B）面板只读取当前显示窗口；差值先以浮点样点计算，再进行色标映射。
- 采样轴不兼容时保留 A/B 显示，并明确禁用差值的原因。
- 新增工业蓝白红色标，可用于叠前和叠后 Image 显示。
- CSV/JSON 匹配报告只包含路径、道集、匹配分类、物理道号、匹配键、道头元数据和采样轴信息，不包含振幅或样点数组。
- 改进同尺寸但关键道头字段缺失的 SEG-Y 配对，提供物理道序回退以便尽可能显示数据。
