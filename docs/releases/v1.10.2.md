# SeisForge Studio v1.10.2

## 叠前原始道序

新增“原始叠前道序”模式，严格按 SEG-Y 文件中的物理道号显示，不按 CMP、炮集、检波点或共 Offset 重排。可设置 1-based 起止道号，并按完整记录、样点范围或毫秒范围读取显示。

现有 CMP、Shot、Receiver 和 Common Offset 道集保持不变。单道分析、道头、频谱、增益快捷键和双击复位继续使用真实物理道号。

## 窗口调整稳定性

叠前窗口调整大小时取消旧尺寸渲染，使用尺寸代次和防抖刷新，松开边界后只执行一次最终渲染。调整过程中保留最后一帧有效图像，并按新的场景矩形裁剪/缩放预览，不再用整块白色占位，避免旧位图在新尺寸场景中留下黑边或黑线。

原始叠前道序采用与 CMP、Shot、Receiver 和共 Offset 相同的两行工具栏布局；窄窗口也保持场景顶部位置稳定，不再额外生成第三行。

右下角进度区域在索引或道集读取期间显示进度条，完成后切换为稳定的“加载完成”文字，不再让满格蓝色进度条看起来像仍在加载。

叠前工具栏的 CMP/Bin、Image/Wiggle、排序、横轴、色标和原始样点模式下拉框统一设置了可见行数、下拉宽度和稳定的原生下拉样式，避免点击后列表不展开。

原生下拉框布局保留弹出列表高度，选择通知延后提交；列表展开期间不拦截其快捷键和鼠标捕获。键值列表显式启用垂直滚动条，可用滚轮、滚动条和键盘浏览全部 CMP、Shot、Receiver 和 Offset 键值。

每类道集的键值列表首项为“全部范围”，显示全部物理道，并继续保留单个道集和共 Offset 分箱选项。原始叠前道序仍使用独立的道号及样点/时间范围控件。

当前测试程序为 `SeisForgeStudio_v1.10.2_prestack_all_range_scroll_x64.exe`；校验值见仓库根目录 `SHA256SUMS_v1.10.2.txt`。EXE 和原始地震数据不纳入源码提交。

数据中的极端振幅在增益裁剪后仍可能显示为色标黑端。程序会提示该情况，但不会自动修改原始振幅或插值替换异常道。

## 兼容性

本版本不修改 `.lidx`、`.cidx`、`.pidx`、`.ptx` 及既有 JSON 参数格式，不改变普通二维、规则三维、弯线和伪三维显示逻辑。
