# SeisForge Studio 1.10.3

## Prestack QC and acquisition linkage

- Added a metadata-only QC page with file/gather statistics and Fold, Offset and Azimuth distributions.
- Added CSV/JSON QC export without amplitude data.
- Stabilized native gather selection, asynchronous generation checks and window-resize preview.
- Added Source–Receiver Geometry selection, counterpart highlighting and dynamic connection lines.
- Ctrl+click continues to open the existing single-trace analysis with real physical trace metadata.

## Compatibility

Ordinary 2D, crooked 2D, true 3D, pseudo-3D, SEG-Y analysis, palettes, gain/AGC, camera settings and existing index/JSON formats are unchanged. NMO, stacking, interpolation, A/B matching and SEG-Y write-back remain out of scope.

Build artifact: `SeisForgeStudio_v1.10.3_prestack_qc_x64.exe` (Windows GUI subsystem).
