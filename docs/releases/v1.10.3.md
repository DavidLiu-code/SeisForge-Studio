# SeisForge Studio 1.10.3

## Prestack QC and acquisition linkage

- Added a metadata-only QC page with file/gather statistics and Fold, Offset and Azimuth distributions.
- Added CSV/JSON QC export without amplitude data.
- Stabilized native gather selection, asynchronous generation checks and window-resize preview.
- Added Source–Receiver Geometry selection, counterpart highlighting and dynamic connection lines.
- Added Azimuth as a first-level gather category with configurable in-memory binning and multi-key selection.
- Fixed Wiggle decimation so 1x/2x/4x/5x/8x changes the rendered trace columns instead of only changing the control.
- Added multi-key gather commands and retained the complete scrollable key lists for all gather types.
- Ctrl+click continues to open the existing single-trace analysis with real physical trace metadata.
- Added a read-only Prestack A/B Compare foundation with independent B indexing,
  metadata matching, sample-axis compatibility checks, clipped A/B/Δ panels and
  CSV/JSON match reports; incompatible axes keep A/B visible and disable Δ.

## Compatibility

Ordinary 2D, crooked 2D, true 3D, pseudo-3D, SEG-Y analysis, palettes, gain/AGC, camera settings and existing index/JSON formats are unchanged. NMO, stacking, interpolation, AVO, Rebin, GPU/Python processing and SEG-Y write-back remain out of scope.
