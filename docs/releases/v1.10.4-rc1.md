# SeisForge Studio 1.10.4-rc1

这是叠前只读 A/B Compare 的候选版本，基于提交 `5e2daa7`。候选版保留
`v1.10.3` 标签和历史发布文件，不覆盖既有产物。

## 主要内容

- A、B 使用独立 Dataset、Reader、道头映射、索引、取消函数和代次。
- 通过 Source/Receiver ID、缩放后的 XY、CDP 与有符号 Offset 进行可审计匹配，保持 A 道集顺序。
- A、B、Δ 面板只读取当前显示窗口；Δ 先进行浮点差值，再进行色标映射。
- 采样轴不兼容时保留 A/B 显示并明确禁用 Δ 的原因。
- CSV/JSON 匹配报告只包含路径、道集、匹配分类、物理道号、匹配键、道头元数据和采样轴信息，不包含振幅或样点数组。
- QC、Geometry、普通二维、弯线、真三维、伪三维和 SEG-Y 分析保持原有数据格式与读取边界。

## 构建与验证

```powershell
go test ./... -count=1
.\build_windows_release.ps1 -Output SeisForgeStudio_v1.10.4-rc1_compare_x64.exe
```

发布构建使用 `-H=windowsgui`，PE Subsystem 必须为 Windows GUI `2`。
候选文件的 SHA-256 只在实际构建完成后写入仓库根目录的
`SHA256SUMS_v1.10.4-rc1.txt`。

## 范围边界

本候选版不包含 NMO、速度分析、叠加、AVO、振幅插值、Rebin、GPU/Python
处理链、持久化 `.pidx` 变更或 SEG-Y 写回，也不修改源 SEG-Y、现有缓存格式
和 JSON 参数文件。

真实测区验收仅在提供脱敏或有权使用的数据时执行；未提供时以 synthetic
SEG-Y Reader 重开测试作为可重复门禁，并在验收日志中标记真实数据测试为 skipped。
