# SeisForge Studio 1.9.15

**Seismic Visualization, Reconstruction & Enhancement**<br>
**震铸地震数据处理平台**

这是项目以 **SeisForge Studio** 品牌发布的首个公开版本。1.9.15 是一款面向 Windows x64 的本地 SEG-Y 浏览、质量检查与轻量分析工具；项目此前使用 Limage 名称，现有配置、索引与许可证路径继续兼容。

## 主要能力

- 二维剖面：Inline、Crossline 和 Time Slice 浏览，A/B 联动、差值、频谱、标注与剖面导出。
- 规则三维：三正交切片、共享振幅归一化、相机与轴倍率控制、A/B/差值和范围导出。
- 二维叠后弯线：单文件、多文件或文件夹项目，XY Geometry 总图，以及 Trace、CDP、Distance 横轴。
- 伪三维幕布：按真实 XY-Time 位置显示多条弯线，支持测线筛选、空间 AOI、时间窗、二维联动和范围导出。
- SEG-Y 分析：文本卷头、二进制卷头、240 字节道头、原始 Hex、单道波形、统计与频谱。

本版本还将卷头和道头字段改为原生表格，采用固定列、网格与筛选，便于连续比较不同道的同一字段。

## 下载与校验

从本 Release 的 **Assets** 下载：

- `SeisForgeStudio_v1.9.15_windows_x64.exe`
- `SHA256SUMS_v1.9.15.txt`
- GitHub 自动生成的源码归档（如需自行构建）

请以同一 Release 中提供的校验文件为准。可在 PowerShell 中自行计算：

```powershell
Get-FileHash .\SeisForgeStudio_v1.9.15_windows_x64.exe -Algorithm SHA256
```

计算结果应与 Release 校验文件中的 SHA-256 完全一致。不要使用第三方转载且无法校验来源的可执行文件。

## 系统要求

- Windows x64。
- 程序为原生桌面应用，不需要单独安装 Go、Python、OpenGL 或其他运行时。
- 建议先在非关键数据副本上熟悉工作区、坐标字节和导出设置。

## 数据与隐私

SEG-Y 读取、几何识别、缓存、分析和渲染均在本机完成。程序不会为了显示或分析而上传地震振幅、坐标、测线名称或卷头内容。

提交 Issue 时请勿附带客户数据、保密坐标或完整 SEG-Y。若问题必须依赖样例，请提供经过授权、脱敏并尽可能精简的复现文件。

## Limage 兼容说明

- 历史文档和旧文件名中的 **Limage/Fimage** 是项目沿革记录，不代表当前产品名称。
- 为避免破坏既有安装，1.9.15 仍读取 `%LOCALAPPDATA%\Limage` 下的用户设置、缓存元数据和许可证状态。
- `.lidx`、`.cidx`、`.ptx` 以及现有 JSON 配置格式保持兼容；不要仅因品牌更名手工移动或批量重命名这些文件。
- 旧版 Limage 可执行文件与本版本相互独立。升级前建议保留原程序和重要配置的备份。
