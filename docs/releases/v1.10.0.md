# SeisForge Studio 1.10.0 — Prestack MVP

本版增加独立的“叠前道集”工作区；普通二维、规则三维、弯线和伪三维入口保持原有语义。

## 使用流程

1. 首页选择“叠前道集”，打开 SEG-Y；也可向叠前工作区拖入文件。
2. 查看道头映射，核对 CMP、Shot、Receiver、Offset 和坐标来源。低置信度时先修改字节并确认。
3. 建立索引后，使用 CMP/Shot/Receiver 类型和上一组/下一组浏览实际存在的道集。
4. Geometry 图层查看炮点、检波点、中点和 Fold，双击 Bin 打开对应 CMP 道集。
5. 点击道查看真实物理道号对应的道头、波形和频谱。

在道集图像中，普通双击恢复当前 Trace/时间窗口；按住 Ctrl 单击才打开单道分析。`Q/W` 调整增益，`E/Shift+E` 切换色标，`R` 保留为上一色标快捷键。图像标题、底部横轴和状态栏会显示 Offset 范围，Offset 横轴模式还会显示首、中、末实际 Offset 值。

坐标比例只应用于相应坐标字段，不机械应用于 Offset。索引只保存道头信息，振幅按道集和样点窗读取。头字段不足时会显示警告，不会把缺失信息伪造为规则三维体。

## 本轮边界

本轮提供单数据集的索引、Geometry/Fold、道集导航、Image/Wiggle 和映射功能。
A/B 对比、Rebin、持久化 `.pidx` 与处理算法尚未实现。Compare 页为明确的后续功能提示。
不执行 NMO、叠加、速度分析、去噪或写回 SEG-Y。

索引与映射仅在当前会话保留；重新打开可能需要重新扫描道头。
既有缓存和视图参数格式不变，Recent 在原格式中新增 mode 4。

## 构建

输出文件：`SeisForgeStudio_v1.10.0_prestack_mvp_x64.exe`。
使用 `build_windows_release.ps1` 执行回归测试、GUI 构建及 PE Subsystem 校验。
旧版 EXE 不覆盖。本轮为本地交付，不自动提交或发布 GitHub Release。

更多实现边界见 `docs/architecture/ARCHITECTURE_PRESTACK_MVP.md`。
