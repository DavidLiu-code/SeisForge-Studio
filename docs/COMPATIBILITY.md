# 兼容性与旧名称迁移

SeisForge Studio 1.9.15 从 Limage 品牌迁移，但保持现有数据、设置、索引和许可证可用。品牌变化不改变 SEG-Y 内容，也不会自动移动用户文件。

## 保留的本地目录

当前版本继续使用历史目录：

```text
%LOCALAPPDATA%\Limage\
```

其中可能包含：

| 文件 | 用途 |
| --- | --- |
| `start_center.json` | 最近打开项目和上次工作区 |
| `volume_view.json` | 真三维默认视图（schema v1） |
| `crooked_view.json` | 弯线横轴、坐标来源、色标和增益（schema v1） |
| `crooked_style.json` | Geometry/伪三维共享风格（schema v1） |
| `pseudo_view.json` | 伪三维默认相机和轴倍率（schema v2，兼容读取 v1） |
| `license.lic` | 已安装的离线许可证 |
| `clock.state` | 离线许可证的本机时间状态 |
| `workspace_trace.log` | 工作区和异步加载诊断事件 |
| `home3d_trace.log` | 历史首页三维入口诊断记录 |

请勿因为界面名称变化而手工改名该目录。丢失或移动文件可能导致视图恢复为默认值、Recent 清空、缓存重建或许可证需要重新安装。

## 缓存兼容

Windows 用户缓存目录下的历史 `Limage` 子目录继续保存：

- `geometry/*.lidx`：规则三维几何索引 v1。
- `geometry/*.cidx`：弯线逐道坐标索引 v1。
- `pseudo_textures/*.ptx`：伪三维八位索引纹理 v1，默认 LRU 上限 1 GiB。

缓存键包含源文件路径、大小、修改时间和相关读取参数。源文件或参数变化时，程序会忽略不匹配记录并重新建立。缓存不包含原始浮点振幅；删除缓存不会删除 SEG-Y，但下一次打开会重新计算。

内部 cache magic 仍以旧名称开头，这是文件格式兼容要求，不代表当前品牌。

## Recent 与工作区编号

`start_center.json` 继续使用数字工作区模式：

- `1`：二维剖面
- `2`：三维数据体
- `3`：二维叠后弯线

单文件、文件夹项目和多选弯线项目均沿用现有记录结构。不要手工改写编号或路径数组。

## 许可证兼容

1.9.15 保留既有机器码、签名载荷和时间状态派生规则，使已签发许可证继续有效。界面名称改变不会重新生成机器码。

## SEG-Y 与导出兼容

- 读取和分析操作不会修改源 SEG-Y。
- 普通剖面、三维范围和伪三维范围导出写入新文件；不会把结果覆盖回源文件。
- 裁剪导出保留源端序和受支持样点编码，并仅更新输出范围所需的头字段。
- `.lidx`、`.cidx`、`.ptx` 与各 JSON schema 在本次品牌迁移中不升级。

## 回退

若需要临时运行旧版 Limage，可保留原可执行文件。由于新旧版本共享历史配置目录，建议在测试重大设置变更前备份 `%LOCALAPPDATA%\Limage`。不要同时让多个版本修改同一配置文件。
