# Limage v1.4.4 — CIGVis camera and highlight refinement

This version continues the CIGVis-oriented 3-D cleanup.

## Main refinements

1. **Closer default camera**
   - Updated the default orthographic turntable view to a gentler, more CIGVis-like opening angle.
   - Slightly reduced default zoom for a cleaner first impression.

2. **Even simpler minimal mode**
   - In minimal mode, the outer cube wireframe is now removed entirely.
   - The scene is now driven mainly by the three orthogonal seismic slices and the time ruler.

3. **Cleaner highlight hierarchy**
   - Active slice outline: muted blue.
   - Hover slice outline: yellow.
   - Dragging slice outline: orange.
   - Slice intersection lines are thinner in minimal mode.

4. **Less visual clutter**
   - The right-side time ruler is slightly tighter.
   - Slice opacities are made more opaque so the three planes feel cleaner and less noisy.
   - The background is slightly brighter.

## Result

The default 3-D appearance is now more minimal and visually closer to the clean CIGVis orthoslice presentation.
