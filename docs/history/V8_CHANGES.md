# Limage v8 changes

## Branding

- Application: **Limage**
- Version line: **Limage v1.5.1 [x64]**
- Contact: **GitHub Issues**

## Feedback button

The original toolbar feedback icon is retained. Clicking it now asks Windows to open the default mail application using:

`https://github.com/DavidLiu-code/SeisForge-Studio/issues`

If Windows cannot handle the `mailto:` request, a dialog shows the email address instead.

## Compatibility retained

All v7 seismic functionality remains unchanged: range-first loading, cached Open, sample-window I/O, >4 GB offsets, axes, zoom, color maps, Min/Max clipping, and percentile-style display gain.
