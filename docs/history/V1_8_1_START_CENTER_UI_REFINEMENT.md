# Limage v1.8.1 — Start Center 与 3D 工具栏收口

## 1. 正式 Start Center

v1.8.0 的三个工作区按钮已改成完整的 Limage 首页：

- 页面主标题：`开始使用 Limage`。
- 三张原生 Win32 自绘工作区卡片：
  - 二维剖面；
  - 三维数据体；
  - 弯曲测线。
- 卡片使用白底、浅灰边框、圆角、蓝色线性图标和轻量 hover 状态。
- 中文作为主视觉语言，不再使用中英文同权重的按钮式排版。
- 首页不显示“方向”、IL/XL/T、色标、标注等工作区内部参数。

## 2. 大面积 SEG-Y Drop Zone

首页中央增加独立的 SEG-Y 打开区域：

- `将 SEG-Y 文件拖到这里即可打开`；
- 明确显示 `.sgy / .segy`；
- 同一区域提供 `选择 SEG-Y 文件`；
- 直接选择文件和首页拖入文件都不要求用户先进入一个工作区。

对于没有明确指定工作区的首页打开/拖放，Limage 只读取少量 trace header 做轻量推荐：

- 可靠识别出二维 IL/XL 网格 -> 推荐并进入三维数据体；
- 不能可靠识别 3D 网格 -> 安全进入二维剖面；
- 弯线暂不依赖启发式自动判断，避免普通 2D 测线误判；后续与 XY geometry/map 联动后再启用弯线自动推荐。

显式点击“二维 / 三维 / 弯线”卡片时，用户选择的工作区优先于自动推荐。

## 3. 最近打开与“上次使用”

新增本地 Start Center 状态：

`%LOCALAPPDATA%\\Limage\\start_center.json`

保存内容：

- 最近最多 8 个 SEG-Y；
- 文件上次打开时间；
- 当时使用的工作区；
- 上次使用的工作区。

首页显示最近文件列表，点击即可按上次工作区再次打开。三个工作区卡片中，上次使用的工作区带轻量 `上次使用` 标记，但软件仍然保留首页，不强制自动进入。

## 4. 文件与视图进一步分离

首页现在支持两条主路径：

1. `工作区卡片 -> 选择 SEG-Y -> 打开`；
2. `直接拖入/选择 SEG-Y -> 自动推荐工作区 -> 打开`。

高级范围选择仍保留在进入工作区后的原有“打开”功能中，因此快速首页与专业数据加载参数并不冲突。

## 5. 3D Volume 工具栏简化

- 删除可见的 `交互` 下拉框；
- 始终使用默认 CIGVis-style 交互：
  - 左键旋转；
  - Ctrl + 左键拖切片；
  - Shift + 左键平移；
  - 右键拖动 / 滚轮缩放。
- 旧版 `volume_view.json` 中可能保存的 interaction 值继续兼容读取，但 v1.8.1 不再应用非默认模式。

## 6. 风格顺序

3D `风格` 下拉框改为：

1. 干净
2. CIGVis
3. 解释
4. 标准

这里只改变 UI 顺序，不改变四种风格的内部定义，也不会把已有保存的风格错误映射到其他模式。

## 7. 兼容性

- v1.7.2 修复的小键盘 NumPad 0–9、NumPad 1/End 区分逻辑保持不变。
- 现有 2D A/B/差、频谱、标注、3D compare、3D 导出和相机快捷键保持原逻辑。
