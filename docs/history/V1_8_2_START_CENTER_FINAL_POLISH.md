# Limage v1.8.2 — Start Center 最终精修

## 1. 三张工作区卡片的交互反馈

Start Center 的三个入口继续保持：

- 二维剖面
- 三维数据体
- 弯曲测线

本版增加完整的交互状态：

- 普通：白底、浅灰边框；
- Hover：蓝色边框、轻微阴影、手型光标；
- Pressed：浅蓝背景、按下反馈；
- `打开 →` 在 Hover 时加强颜色；
- `上次使用` 改为更小、更淡的提示标签，不再像独立按钮。

卡片说明进一步明确：

- 二维：查看单条或二维地震剖面；适合常规 2D 数据浏览；
- 三维：IL / XL / Time 三维联动浏览；适合规则三维体数据；
- 弯线：Crooked-line 地震数据浏览；适合非规则测线 / 弯线数据。

## 2. Drop Zone 强化

SEG-Y 打开区域改为更明确的 Drop Zone：

- 大面积浅色背景；
- 虚线轮廓；
- 简洁文件/拖入图标；
- `.sgy / .segy` 类型提示；
- 保留 `选择 SEG-Y 文件`；
- 普通 Hover 时高亮；
- 从 Windows Explorer 拖着文件进入窗口、尚未松手时，Drop Zone 即进入高亮状态。

Explorer 拖拽反馈使用 Windows OLE `IDropTarget` 的 `DragEnter / DragOver / DragLeave / Drop`。

为了避免一个 Drop 同时被 OLE 与旧的 `WM_DROPFILES` 重复处理：

- OLE 注册成功时关闭该窗口的旧 DragAcceptFiles 通道；
- OLE 注册失败时保留原 `WM_DROPFILES` 作为兼容回退。

因此 v1.8.0/v1.8.1 已有的 SEG-Y 拖放打开逻辑保持不变，只增加更及时的视觉反馈。

## 3. 最近打开区域完善

最近打开不再只是单行文件名，而是完整的工作台列表：

- 最多保留 5 条；
- 文件名；
- 文件所在路径；
- 上次使用的工作区；
- 最近打开时间；
- `打开 →` 快捷动作；
- 每行右侧 `×` 可从最近记录中移除；
- 标题右侧 `清空记录` 可清空整个 Recent 列表。

移除或清空只修改 `%LOCALAPPDATA%\\Limage\\start_center.json`，不会删除磁盘上的 SEG-Y 文件。

没有最近记录时会显示轻量空状态提示，而不是留一块空白区域。

## 4. 页面层级和间距

- 主标题、副标题和卡片整体略向上收紧；
- 卡片、Drop Zone、Recent 之间的垂直间距缩小；
- 版本号进一步变淡，只作为元信息；
- Recent 区域在常见窗口高度下优先显示 4–5 条记录；
- 首页继续隐藏方向、IL/XL/T、色标等工作区内部参数。

## 5. 数据与工作区逻辑不变

继续保留：

- 显式点击二维 / 三维 / 弯线卡片时，以用户选择为准；
- 首页直接选择或拖入 SEG-Y 时进行轻量 Header 检查；
- 可靠识别出规则 IL/XL 网格时推荐三维；
- 否则安全进入二维；
- 弯线自动推荐仍等待后续 XY Geometry / Map 联动后再启用，避免普通二维测线误判。

## 6. 3D Volume 保持当前收口

本版不重新改变 3D 交互架构：

- `交互` 下拉框仍然不显示；
- 始终使用默认 CIGVis-style 交互；
- `风格` 顺序仍为：
  1. 干净
  2. CIGVis
  3. 解释
  4. 标准

`干净` 继续位于最上方，因为它的辅助线最少。

## 7. 回归兼容

- v1.7.2 的 NumPad 0–9、NumPad 1 / End 区分逻辑保持不变；
- A/B/差、频谱、标注、3D 对比、3D 导出、相机快捷键保持原逻辑；
- 原 `start_center.json` 可直接继续使用，多于 5 条的旧记录会自动收敛到最近 5 条。
