# Limage v1.8.3 — 体内二维切片风格同步

## 目标

从 3D Volume 中双击 Inline / Crossline / Time Slice 进入 `2D Full View` 后，顶部“风格”选项继续生效，并与三维体中的视觉语义保持一致。

本次仅改变辅助信息层，不改变 SEG-Y 数据、振幅、增益、色标、IL/XL/Time 位置或三维相机。

## 四种风格在 2D Full View 中的对应关系

### 干净

- 只显示地震纹理与必要坐标文字。
- 不显示切片外框。
- 不显示三维切片交会辅助线。
- 不显示鼠标移动十字线。

这是线条最少的模式，继续位于“风格”列表第一项。

### CIGVis

- 不显示切片外框。
- 保留当前三维交点对应的两条细交会线。
- 交会线采用低干扰的中性浅灰。
- 鼠标移动不额外叠加十字线。

### 解释

- 显示轻量切片边界。
- 显示当前三维交点的两条交会线。
- 鼠标定位采用短距离局部十字线，避免整幅贯穿线遮挡反射特征。

### 标准

- 显示更明确的切片边界。
- 显示当前三维交点的两条交会线。
- 鼠标定位采用贯穿整个切片的完整十字线，定位信息最完整。

## 交互

- 在 3D 中双击任一切片进入 2D Full View。
- 进入 2D 后无需返回 3D，可直接切换顶部“风格”。
- 风格变化立即重绘当前二维切片。
- 双击或 `Esc` 返回 3D，切片位置保持不变。

## 保留行为

- 风格顺序仍为：`干净 -> CIGVis -> 解释 -> 标准`。
- 3D 默认交互不变。
- v1.7.2 NumPad 1 / End 修复保持不变。
- Start Center、SEG-Y 拖放、Recent 文件逻辑保持不变。
