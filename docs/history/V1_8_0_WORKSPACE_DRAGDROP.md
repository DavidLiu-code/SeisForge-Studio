# Limage v1.8.0 — 简洁工作区入口与 SEG-Y 原生拖放

## 1. 新的启动入口

程序首次启动且尚未加载数据时，不再直接显示完整 QC 控件，而是显示三个简洁工作区入口：

- **二维剖面 / 2D Line**：进入现有二维剖面浏览与 QC 工作区。
- **三维数据体 / 3D Volume**：选择 SEG-Y 后自动进入现有三维正交切片 / 体显示窗口。
- **弯曲测线 / Crooked Line**：进入独立标识的弯线工作区；当前按 SEG-Y 道序展开二维剖面，并保留自动几何识别、比/差、频谱和标注能力。后续 XY 几何地图可继续挂接在该入口下，不与规则二维/三维工作区混杂。

加载数据后，启动卡片自动隐藏，恢复原有完整工具栏和浏览控件。

## 2. Windows 原生 SEG-Y 拖放

新增 Shell `WM_DROPFILES` 支持，不依赖模拟鼠标事件。

### 欢迎页 / 2D 工作区

- 拖入一个 `.sgy` / `.segy`：直接作为 **A** 打开。
- 已有 A 时再拖入一个 SEG-Y：不覆盖 A，直接作为 **B** 加载并进入现有“比”工作流。
- 一次拖入两个 SEG-Y：第一个作为 A，第二个作为 B。
- 一次拖入超过两个文件：只使用前两个并给出提示。

### 3D 窗口

- 在已打开的 3D Volume 窗口中拖入另一个 SEG-Y：直接作为 **3D B** 加载。
- B 自动映射到与 A 最接近的 IL / XL / 物理时间位置，并进入现有左右 3D 对比模式。
- 原有“与左图一致”“差”“出”等 3D QC 功能保持不变。

### 数据加载对话框

数据加载对话框本身也接受 `.sgy` / `.segy` 拖放；拖入后自动探测卷头并填充道数、采样点、采样率和时间范围。

## 3. NumPad 修复保持不变

v1.7.2 的数字小键盘修复完整保留：

- NumPad 0–9；
- 小键盘小数点、加号、减号；
- NumLock 关闭时，物理 NumPad-1 虽由 Windows 报告为 `End`，仍会被识别为数字 `1`；
- 独立键盘 `End` 仍保持导航键含义；
- 3D 导出范围框中 Enter 执行导出、Esc 关闭。

本版本未改动 3D 快捷键路由。

## 4. 文件类型

拖放当前接受：

- `*.sgy`
- `*.segy`

其他扩展名不会被误当作 SEG-Y 打开。
