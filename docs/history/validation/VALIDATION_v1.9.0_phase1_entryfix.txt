Limage v1.9.0 Phase 1.2 entry mapping validation
Date: 2026-08-24

Observed failure:
  Home card "二维剖面" opened the automatic/3-D route.
  Home card "三维数据体" opened the 2-D route.

Root cause:
  WM_DROPFILES and workspace modes shared one iota declaration. Because
  WM_DROPFILES consumed iota=0, the intended persisted workspace values
  1/2/3 became 2/3/4. Home cards still passed cardIndex+1 (1/2/3), reversing
  the first two entries and misrouting Crooked.

Fix:
  WM_DROPFILES is declared separately.
  Workspace modes are explicit persisted values:
    Line2D  = 1
    Volume3D = 2
    Crooked = 3

Regression assertions:
  - Persisted numeric contract is exactly 1/2/3.
  - Win32-to-core mapping: 1->Line2D, 2->Volume3D, 3->Crooked.
  - Core-to-Win32 mapping round-trips all three modes.
  - Full go test ./... -count=1: PASS.
  - %SEISFORGE_TEST_ROUTE_FILE% automatic route remains Regular3D under the prior
    duplicate-Inline fix.
