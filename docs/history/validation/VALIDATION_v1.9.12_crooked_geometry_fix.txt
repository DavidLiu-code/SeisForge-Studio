Implemented contracts
- The XY project overview uses one canonical trajectory derived from calibrated
  per-trace SEG-Y header coordinates for bounds, drawing, hit-testing and cursor
  placement. DAT navigation is calibration input only.
- Active/inactive selection changes styling only and cannot replace the map
  trajectory or project bounds.
- A map click keeps line ID, trace index, project/header generations and a
  geometry fingerprint until the selected section is ready.
- Every valid project line, including lines with DAT navigation, is prepared in
  the background. The overview and line selector become interactive only after
  every line has either a canonical geometry or a reported error.
- Raw .cidx geometry remains unmodified. Decimal scale and constant X/Y
  translation are applied to a derived copy.
- Derived pseudo-3-D texture cache algorithm version was advanced to 3.
  Its key includes the final canonical geometry fingerprint, so mixed 0.1/1.0
  coordinate scales, translations and old navigation-only textures cannot be
  reused or rescaled a second time.
- Lines whose DAT/header calibration failed remain excluded from the overview,
  range tools and pseudo-3-D. DAT never becomes a fallback display geometry.
- Hide/Show resumes unfinished header geometry and an interrupted active
  section without duplicating completed or failed jobs. Header-setting changes
  invalidate pseudo-3-D before rebuilding the canonical project geometry.
- Concurrent cold .cidx writers use unique temporary files and an atomic
  in-process Windows commit; the cache format and raw geometry remain unchanged.
