# 色标和坐标编辑

## 叠后波形、快捷键与显示范围

在普通叠后或 Compare 打开「参数 → 波形显示」。默认是彩色图（支持灰度色表）；另可选波形图、波形＋变面积、变面积图。黑白方案用黑线表示正负波形，仅填黑正区；黑红为正黑负红。「反转颜色」只交换着色，不翻转波形。BMP 使用相同绘制分支。

- 模式与摆幅：默认 `1×`，可选 `0.5 / 1 / 1.5 / 2 / 3` 或输入自定义值。用真实道中心的可见间距确定绘图宽度（拥挤时设可读下限），不随绘制抽稀变化。参考振幅可以手动输入正值，或自动统计**全部可见道及时间范围内**的有效绝对振幅；默认使用近似 P98，Q/W 调整显示参考的百分位。超出参考幅值的样点不做振幅截顶。同图不逐道归一；联动的 B 使用 A 的参考，差图按已有“跟随 A／独立”配置取参考。
- 绘制密度：自动按约 `12 DIP` 留白、全部可见道、每隔 `K` 道。可在自动模式设置最小道距（原横轴单位，`0` 为自动）。不会移动道中心、填补空道或缩短算法处理范围。
- 曲线与填充：默认 `1 DIP`、填充完全不透明、零基线关闭；可独立选正负区域的颜色及显隐。恢复波形默认只修改波形参数草稿。
- 绘制质量：默认以浮点位置线性连接样点、抗锯齿；时间步长 `0` 绘制全部真实样点。自定义步长只影响显示抽样，并保留过零和缺失边界；采样轴和数值导出保持不变。
- `Q / W` 将原版显示增益提高／降低 1 个百分点，限 `0–49%`。这是百分位裁剪控制，不是对 SEG-Y 样点乘系数。明确锁定色标范围或波形参考时，该设置优先；恢复色标增益范围用「参数 → 其它设置 → 改用 Q/W 增益范围」，然后应用。

波形使用当前视图样值（含已启用的显示滤波），不会改变处理输入、A/B 数值或 SEG-Y 导出。几何编号的手动定位和道头字节设置均在「几何设置」，两者不会相互提交草稿。

## 编辑色标和坐标

双击图外的轴线、刻度、轴标题或可见色标，打开该窗口自己的“显示设置”。普通剖面和叠后对比工具栏的彩色色标图标也打开同一个窗口；旁边的色表下拉框仍用于快速换色。新打开的数据和对比面板默认隐藏色标条。在色标“外观”页勾选或取消“主图显示色标”后点击“应用”，也可通过绘图区右键直接切换。显隐只作用于当前数据和面板，不会带到下一个文件。窗口里先编辑草稿，点击“应用”或“确定”才改图。“取消”不会撤销此前已成功应用的设置。换文件、换正式 B 或切换着色值域后，重新从当前图上选择对象。

色标的“范围”页可拖动振幅区间的两端，或拖动中段平移，最小值和最大值输入框仍可精确编辑。自动格式下，振幅绝对值达到 10,000 时不显示小数，达到 1,000,000 时用科学计数；此规则适用于色标主刻度、色标端点和只读振幅读数，不改变实际振幅映射、输入精度或数据。手动数字格式保持原设定。

| 视图 | 接入 |
| --- | --- |
| 普通二维、叠后剖面和 Time Slice | 二维轴、当前幅值色标；保存 BMP 包含已显示的轴、色标，Compare 还包含标注 |
| 叠前 Gather 与 Compare | 保留原有色标、显示范围和坐标控制及 Figure 重放，不接入本版叠后显示设置 |
| 弯线剖面和弯线平面图 | 各自的坐标；弯线剖面幅值色标 |
| 叠前 Geometry 和 QC 图表 | 共享只读图表显示适配；坐标显示设置不改采集几何、Fold 值或统计分箱 |
| 频谱和单道分析 | 每个图的范围、单位与样式；不改变 FFT 或频谱标定 |
| 真三维和伪三维 | 正交轴样式、当前切片或幕布色标；范围和方向只读，现有相机与裁剪不变 |

真实范围在可见的逻辑样点上统计，无效值不等于零。分布图超过采样预算时标为“抽样分布”，极值仍精确。当前 A/B/差使用数值数据；局部 B 不补零。AGC 的颜色单位是归一化显示值，不是物理振幅。伪三维旧模式允许不同幕布分别自动归一化，这时不会为不同尺度伪造共同色标；明确应用一个范围后才显示统一渐变。

叠后对比的色标页和坐标页均可通过“编辑对象”选择 A、B 或差值。只要面板已显示图像，即使色标条已隐藏也可以选择；三个面板分别勾选“主图显示色标”。时间剖面的 B 和差值默认在坐标页“与 A 一致”，复用 A 的真实刻度位置，而不是只复制数字格式；显式解除后才独立，更换同一 A 的 B 时保留明确选择。可见范围如果仅覆盖 A 刻度的子集，只显示合法位置，不拉伸缺失覆盖。色标跟随单独控制；坐标继承不会改变振幅映射、真实几何或数值。叠前对比仍可使用原有全局“色标模式”。修改色标不会执行滤波或生成 B。

显示设置使用两级原生页签，不用滚动。在“范围 / 刻度 / 外观”之间切换，色标另有“渐变”。普通叠后和对比的范围可精确输入或拖动；拖动中段保持跨度，零对称色标只允许拖动两端。Esc 只撤销当前未完成的拖动。主图轴带仍用于直接导航；对比三幅图共用实际视窗。

“范围”页的参数在上，分布图和范围编辑条在下。数据范围是当前有效样点的统计；“主图已应用范围”是当前着色范围；“草稿范围”用于设置窗口预览，应用后才影响主图。“刻度”和“外观”的效果预览遵循草稿里的显隐设置；关闭色标时，“范围”和“渐变”仍保留用于操作的编辑色带。

色标范围方式为数据全范围、样点百分位和手动。中央 98% 表示 P1–P99；“占完整数值跨度 %”是另一个操作，例如 0～10000 的 1%～99% 对应 100～9900，与样点分布无关。百分位先求端点再施加零对称。分布超过抽样预算时，百分位估算和实际覆盖率会明确标注；精确极值仍保留。色标单位只作标题标注，不换算振幅，BMP 使用同一标题与布局。跟随 A 只继承有效色表和映射，标题、单位和显隐仍独立，解除跟随后从当前有效映射开始编辑。

短读数不会覆盖内部浮点端点；用“复制精确值”查看和保留完整数值。“复制设置到…”先暂存指定面板与字段，再由底部统一应用。默认只复制刻度和字体；标题／单位、色表和精确色标端点须明确勾选。复制端点转为手动，不复制 X/Y 视窗或数据。

普通叠后时间剖面与叠后对比的“刻度”页使用 N 等分。X、Y 与色标分别选择 1–20 段（默认 5），只读计算间隔随范围更新。等分基于当前实际视窗或色标映射上下限，不是文件全范围或样点极值。可单独调整刻度长度、数字格式、精度和字号；长度为 0 只隐藏刻度线。窗口缩小后保留刻度位置，空间不足时提示并优先保留首尾刻度标签。其他视图继续使用原有自动或手动间隔。BMP 使用与屏幕一致的绘制布局；显示设置不改变源数据或滤波结果。

新建和恢复默认的刻度使用整数，已经明确选择的数字格式仍保留。普通叠后及剖面对比的 X/Y 在整数模式下，把目标等分位置按当前显示单位取整（半值远离零），去除重复及越界刻度，再按实际坐标绘制。设置窗口区分目标等分间隔、实际整数间隔和刻度数；真实视窗边界、道号、样点和振幅映射保持原精度。一个有效道保留自身精确坐标，只画一个横轴刻度；色标整数模式仍只影响振幅标签。刻度文字支持 5–36 pt（默认 10 pt）；字号、长度暂未通过校验时显示上次有效样式，保留可计算的间隔。标签排版警告不会阻止应用有效设置。横轴使用宽短预览；范围页的选择标尺表示完整数据边界，而非裁剪后的坐标轴。

“渐变”页的点位是映射范围内的 0–100%，与上方直方图的完整数据范围不同。点击色带空白处设定待添加位置，双击空白可以直接添加，双击已有点则改色。两端点可改色但不可移动或删除；内部点可拖动、精确输入或在色带拥有焦点时按 Delete 删除。新增点继承当前位置的颜色，不替换原有色表。

普通叠后时间剖面的空间轴可改为“距离”。Inline 剖面采用 Crossline 方向的间距，Crossline 剖面反之。自动依次检查带 m/ft 单位的 SEG-Y 文本卷头 `INLINE SPACING` / `CROSSLINE SPACING`、单位明确且已应用比例因子的 CDP XY，最后使用明确标为假设的 20 m。手动间距输入始终是米。A 的完整原始剖面首道中心为共同零点；裁窗和局部 B 不重新归零。已确认的缺道位置留空，未确认的网格不凭编号猜测缺口。视窗两端的最大绝对距离超过 1000 m 时全轴统一使用 km。

显示样式与旧配置分开写入用户配置目录下的 `display_settings_v1.json`；样式按视图类型复用。不把旧数据的坐标区间或绝对幅值区间套到新文件。XYZ 三维模型或数据型导出的格式没有变化。

剖面默认仍为彩色图；首次切换到波形显示时采用黑红极性方案。单道分析的 A/B/差则用不同来源线型和颜色，见 [叠后单道与科研图](SCIENTIFIC_FIGURES.md)。
