# 安装和使用外部算法模块

本功能从叠后 Compare 的“算法处理…”入口打开独立窗口。主程序负责读取当前可见剖面、显示和导出；外部模块只接收独立 artifact，不接收源 SEG-Y 路径。A 文件始终只读。

## 安装

每个模块单独放在以下目录，不要放进 Git 工作树：

```text
%LOCALAPPDATA%\Limage\algorithms\<算法ID>\
    manifest.json
    algorithm.exe
```

通过“模块管理”刷新模块列表，也可显式添加其他模块的 `manifest.json` 或外挂包的 `algorithm-pack.json`。发现过程只读取清单和 EXE 指纹，不启动模块，不搜索 SEG-Y 目录或 PATH。没有外部模块时仍可正常浏览数据，并使用公开内置的“逐道时间滤波”；缺失的私有模块不会被模拟执行。

参数界面来自 manifest；切换算法后显示相应参数、单位和范围，参数较多或屏幕较小时按页浏览。未知 ID、参数错误或版本不兼容会拒绝执行，不会自动使用 Copy 替代。

### 多算法外挂包

安装时保留整个目录，例如 `%LOCALAPPDATA%\Limage\algorithms\<包目录>\`。新宿主也会在自身同目录的 `algorithms` 下查找，或在本次运行手工选中该包的 `algorithm-pack.json`。一个包可以用同一个可执行文件提供多个独立算法 ID；每个算法仍有自己的参数、授权和结果记录。不要同时安装同 ID 的独立模块和外挂包，宿主会拒绝冲突的 ID。

索引只列同目录的算法清单文件名，不递归扫描，不允许透过上级路径、子目录或符号链接访问文件。算法清单沿用公开 `seisforge.algorithm.v1` 描述符，并声明同一个同目录 EXE：

```json
{
  "schema": "seisforge.algorithm-pack.v1",
  "id": "example.pack",
  "version": "1.0.0",
  "manifests": ["first.algorithm.json", "second.algorithm.json"]
}
```

宿主在明确授权后运行 `--describe --algorithm <算法ID>` 检查该描述符；运行命令不变，使用请求 JSON 的 `algorithm_id` 选择方法。单独模块的 `--describe` 仍不带 ID。授权指纹包含包索引、算法清单和工作器；工作器依赖仍须来自可信发行方。更新、移动或替换包后按提示重新授权。

## 运行与结果

1. 在叠后剖面选择需要的道和时间窗，进入“比”。
2. 点击“算法处理…”，选择模块并检查参数。打开窗口本身不启动任务。
3. 首次运行时检查模块路径、manifest 与 EXE 的 SHA-256；只授权自己信任的模块。模块内容改变后必须重新授权。
4. “预览当前窗口”生成一个可替换的临时 B，不进入正式结果列表；“运行处理”把验证通过的 B 加入正式结果列表。两者处理同一可见范围。任务超时默认 30 分钟，可在“运行设置”调整。
5. 校验通过的主输出加载为 B；A/B/差继续使用现有显示控制。更改页面、数据或范围导致的过期任务不会覆盖新 B。
6. 在“处理结果”中选择结果、查看日志或显式导出。没有残差输出的模块不生成 Part1；导出不会覆盖源文件或已有结果。

运行时使用“取消运行”保持窗口开启；若关闭参数窗口，确认后才取消，并等待后台清理后关闭。重开窗口会恢复当前应用会话中的参数草稿及折叠状态。

生成 B 保持输入的 shape、坐标、道序、采样轴和有效掩码，首版不允许算法静默插值或重排。artifact 保留 float32/float64 精度；主程序导出生成结果时使用 IEEE float64 SEG-Y。SEG-Y 无法精确表达的时间原点会被拒绝，而不是悄悄舍入。

Ctrl+单击生成 B 时，读取采用 B 本地索引，显示波形与标线使用对应的 A 原始样点坐标；不会因裁剪而从零重新计时。

## 公开带通模块与频谱视图滤波

“逐道时间滤波”是明确注册的公开主机模块（`seisforge.bandpass.zero_phase`），不是未知算法的回退，也不是未授权 EXE。它使用同一描述符、参数窗口、artifact 校验、取消、结果列表、导出和运行记录链路；外部 manifest 不能覆盖其保留 ID。私有模块的授权规则不变。

- 数值核心为逐道四阶 Butterworth 高通 + 四阶低通 SOS，前后向零相位计算，27 点奇反射补边。至少需要 28 个真实上下文样点；不混合相邻道、不重采样。截止点不是理想砖墙，前后向幅频响应为单向响应的平方。
- `low_hz`、`high_hz` 必须满足 `0 < low < high < Nyquist`。初始草稿沿用原视图预设 Nyquist 的 8% / 65%，根据真实微秒采样间隔计算；修改参数不会自动运行。
- 频谱入口仅改变所选对象的可恢复显示。正式模块始终从 A 的基准源读取当前选中道的完整真实时间序列，滤波后裁回当前时间窗，不读取 A 的滤波显示缓存；两入口调用相同核心和上下文裁剪函数。
- Compare 的共享显示范围取自当前窗口的 A/B 基准数据（或手动设置），不随单侧滤波变化；只滤 B 不会改变 A 的亮度，反之亦然。差值在可见道与时间窗的真实重叠部分用当前样点计算，不对着色结果求差，也不对差值另施加 AGC。
- 输出 B 保留当前窗口、真实道序、坐标和采样轴。新 B 的视图滤波默认关闭；A 的视图设置不被偷偷重置。B 不自动再次滤波。相同输入上下文与参数下，正式 B 和 A 视图结果数值一致。
- 运行记录增加可选 `input_context_fingerprint` 与 `processing_scope`，记录完整读取上下文的 SHA-256、道数、可见样点范围和上下文范围；不保存样点数组。输入可见 artifact 指纹仍单独保留。源身份在计算前、计算中和结果发布前核对。
- 只有“导出结果 SEG-Y”才写出用户结果文件。生成与预览仅产生受生命周期管理的临时 B；A 文件始终不变。

## 外部模块安全

外部 EXE **不是沙箱程序**。Job Object 用于取消和进程生命周期管理，不能阻止恶意模块访问本机文件。不要授权不可信来源的模块。

公开版本不内置私有数值实现。同一个公开主程序可以运行用户另行安装、授权的模块，无需私有 build tag、私有包 import 或本地 go.mod replace。模块及其依赖、权重、训练数据不应提交或打包到公开 Release。

外部可执行文件必须实现公开协议才可注册。对使用其他协议的程序，应在仓库外编写适配器，明确转换输入和输出；不要直接把旧式 worker 当成可安装模块。
