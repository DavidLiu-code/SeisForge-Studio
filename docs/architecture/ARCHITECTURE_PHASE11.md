# Limage Phase 11 架构说明：伪三维时间范围裁剪

## 目标与边界

Phase 11 在弯线项目中增加项目级绝对毫秒时间窗。二维弯线剖面始终显示完整记录，时间窗只影响伪三维幕布的读取、纹理和绘制。XY AOI、相机、测线勾选和时间窗是相互独立的状态；时间窗不写入 Recent 或任何视图 JSON。

本阶段没有修改真三维渲染、相机和 `volume_view.json`，也没有修改 20 套色标、gain/clip、`.lidx`、`.cidx v1` 或 `.ptx v1` 格式。

## 绝对时间坐标

`internal/pseudo3d.TimeRange` 使用 `StartMS/EndMS/Valid` 表示项目统一时间窗，并集中提供归一化、边界限制、包含判断和样点换算。每条测线按自身采样间隔把绝对毫秒换算到最近有效样点，所以不同采样率和不同记录长度不会被强行拉伸。

幕布保存实际的 `TimeStartMS/TimeEndMS`。场景 `Bounds` 同时保存 `TimeMinMS/TimeMaxMS`，投影、Z-buffer、透视校正拾取和二维联动都以绝对时间运算。`PickResult.TimeMS` 可直接返回二维光标，不再从统一高度比例反推时间。

## 二维与伪三维交互

弯线工具栏新增“时间范围”和“清除时间”。时间范围模式只接管下方剖面的垂直拖动：不足 5 像素不提交，Esc 取消，选中后以淡蓝色带和细虚线持续显示。切换活动线时项目时间窗保持不变，较短记录只显示与自身重叠的部分。

伪三维在时间起止面的中央提供 Ctrl 拖动手柄，以避免与既有 XY 外框边角冲突。拖动只更新动态预览并限制约 30 FPS；松开后只增加一次时间代次。双击幕布返回二维、XY AOI 编辑和相机操作保持原样。

二维联动光标位于时间窗外时不会扩大时间范围，也不会打开 Reader；状态栏提示“当前二维时间在伪三维时间范围外”。

## 按时间窗读取与纹理裁剪

每个 `pseudoLoadJob` 携带 `SampleStart/SampleEnd`、实际起止毫秒和时间代次。纹理尺寸规划以选中样点数为高度依据，仍遵守单线 `1024×1536`、总纹理 192 MiB 和全局最多八个块任务的限制。

时间窗变化采用两阶段更新：

1. 若内存中已有覆盖所选时间的纹理，先按 V 区间裁剪为预览，保留相机、测线选择、Geometry 和 XY AOI。
2. 后台按最终样点窗精确读取并重新执行既有 gain、clip、AGC 和自适应映射；精确结果替换预览后才显示“完成”。

窄时间窗读取还收紧了相邻道批量 I/O 的允许间隙。完整或较大时间窗继续采用 Phase 9 的 64 KiB 合并上限；时间窗不超过半条记录时，允许间隙随窗口字节数降低。这样不会为了合并调用而把各道中被裁掉的大段样点重新读入，25% 时间窗的实际读取字节可保持在完整范围的 35% 以内。

## 持久缓存复用

精确缓存键继续使用 `.ptx v1` 已有的 `SampleStart/SampleEnd` 字段，不升级文件格式。查找顺序为：

1. 精确样点窗缓存，命中时不打开 SEG-Y；
2. 覆盖该范围的纹理作为即时预览；
3. SEG-Y 精确样点窗读取。

完整时间缓存不会被删除，所有时间窗仍由现有 1 GiB LRU 管理。由于 `.ptx v1` 文件名是完整键摘要且旧文件不保存可搜索键，磁盘覆盖预览只能在兼容尺寸键可确定时使用；内存中的完整纹理可直接按任意 V 区间裁剪。这个限制保证了缓存格式完全兼容。

## 异步代次与资源生命周期

项目、XY 范围和时间范围分别使用独立代次。Worker、持久缓存结果和 UI 消息必须同时匹配当前窗口代次、空间代次和时间代次。时间窗变化立即取消未开始任务；已经运行的旧任务在块或幕布边界检测到过期后关闭 Reader，结果不得进入窗口。

预览纹理只标记为“时间裁剪预览”，不会计入最终完成。状态栏依次区分“时间裁剪预览”“读取时间窗”“最终渲染”和“完成”，完成信息包含时间范围、耗时和缓存命中数。

## 测试与交付

测试覆盖时间范围反向归一化、边界限制、样点取整、不同记录长度、透视/正交拾取、二维选择、伪三维时间面调整、V 向预览裁剪、精确缓存命中、覆盖缓存预览、过期代次和窄时间窗批量读取。窄窗回归同时断言 25% 样点窗的读取字节不超过完整范围的 35%，纹理高度按所选样点数规划。

在 `%SEISFORGE_TEST_CROOKED_PROJECT_DIR%` 的 62 条有效测线上，自动验收得到：完整时间为 1.559 s、读取 1,653,613,384 字节、保留纹理 97,517,568 字节；50% 项目时间窗为 1.428 s、读取 1,427,723,620 字节、保留纹理 65,599,488 字节；25% 项目时间窗为 0.451 s、读取 200,232,484 字节、保留纹理 32,849,920 字节。25% 窗分别为完整范围读取量的 12.1%、纹理容量的 33.7%，最终显示用时缩短约 71.1%。不同测线记录长度不同，因此“项目 50% 窗”与每条线自身的 50% 样点数并不等价。

独立发布文件为 `Limage_v1.9.9_pseudo_time_x64.exe`，使用 Windows GUI 子系统，不覆盖任何旧版可执行文件。
