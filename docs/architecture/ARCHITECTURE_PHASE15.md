# Limage Phase 15 架构说明：SEG-Y 卷头与道头表格化

## 目标与边界

Phase 15 只调整 SEG-Y 分析窗口中卷头、道头的组织与呈现，不改变 Phase 14 的解析接口、单道振幅读取、统计或频谱算法。原先通过空格拼接的字段文字改为原生 Win32 表格，以解决中文比例字体下的列错位；文本卷头、二进制卷头、道头及完整原始 Hex 均继续保留。

本阶段仍为只读分析：不编辑源 SEG-Y，不猜测未知或厂商扩展字段，不执行全文件逐道扫描，也不修改 `.lidx`、`.cidx`、`.ptx`、Recent 或任何 JSON。二维、弯线、真三维和伪三维的振幅映射、色标、归一化、gain/clip、相机及交互保持原路径。

## 页面与表格模型

卷头页增加页内子标签：

- **文本卷头**保留主卷头/扩展卷头选择与 ASCII/EBCDIC CP037 手动切换，正文使用等宽字体。
- **二进制卷头**显示文件摘要、400 字节字段表格和可折叠的完整 Hex；Hex 默认收起并使用等宽字体。

道头页分为三段：顶部固定显示来源、1-based 道号、IL/XL/CDP/坐标摘要、采样参数一致性与只读警告；中部显示 240 字节字段表格；底部显示默认收起的完整 Hex。警告和摘要不随字段筛选滚出或消失。

二进制卷头与道头共用内部表格行模型，直接包装现有 `segy.HeaderField`，不复制或重新解释 SEG-Y 字节。列顺序固定为：

1. `字节位置（1-based）`
2. `字段`
3. `原始值`
4. `解释值`

字段始终按 SEG-Y 字节位置排序，不允许用户点击列头改变顺序。初始列宽约为 90、230、150 像素，解释列占据剩余客户区；窗口缩放时仅重新分配列宽，不重新读取文件。表格启用浅色横纵网格、整行选择和双缓冲，批量刷新时暂停重绘，填充完成后一次性恢复和失效。

## 字段筛选与显示口径

字段筛选枚举固定为 `全部`、`关键`、`非零`，默认选择 `全部`。筛选在当前结果副本上执行，不启动新的 Reader 或异步任务，并显示“当前 N/M 个字段”。

- 道头关键字段覆盖道序、FFID、CDP、Trace ID、Offset、坐标/高程比例因子、坐标单位、Source/Group/CDP XY、Delay、道内样点数/间隔、Inline、Crossline 和 Shotpoint。
- 二进制卷头关键字段覆盖作业号、测线号、卷号、采样间隔、样点数、格式码、覆盖次数、排序码、计量系统、SEG-Y 版本、定长标志和扩展文本卷头数。
- `非零` 严格使用 `HeaderField.Raw != 0`，零仍是合法值，不被标注为无效或缺失。

解释列沿用解析层给出的解释值和单位。当解释值与原始值文本完全相同且没有单位时，表格显示 `—`，减少重复视觉噪声；比例换算、枚举名称或单位存在时仍显示完整结果，例如 `2000 us` 或 `1（地震数据）`。未知字段和不支持的样点格式继续显示原始值/Hex，不增加推断。

## 选择保持、Hex 与复制

表格刷新前记录当前选中字段的稳定 `HeaderField.Key` 与首个可见字段；切换上一道、下一道、转到道号或 A/B 来源后，优先恢复相同 Key 的选择与可见位置。字段在新来源中不存在或被当前筛选隐藏时，回退到列表首项。筛选切换同样按 Key 恢复选择，避免依赖变化后的行号。

二进制卷头和道头分别保留自己的 Hex 展开状态，状态仅属于当前分析窗口会话，关闭窗口即丢弃，不写入设置文件。Hex 的展开/收起只改变布局和控件可见性，不改变当前数据或触发读取。

“复制当前页”生成带列头的 TSV，字段列依次为字节位置、字段、原始值和解释值，可直接粘贴到 Excel。复制内容包含当前页摘要、始终可见的警告、当前筛选后的字段以及该页完整原始 Hex；文本卷头页复制当前选择的已解码文本。复制不写源文件，也不改变筛选、选择或滚动位置。

## 异步与资源生命周期

Phase 15 沿用 Phase 14 的 `traceAnalysisGeneration`：只有匹配当前窗口、选择和代次的结果可以进入 UI。表格模型只持有 Go 数据副本，不持有 `segy.File`、文件映射或工作区 Reader。快速换道、切换来源或关闭窗口后，过期 Worker 必须关闭其独立 Reader，过期结果不得更新 ListView、摘要或 Hex。

ListView、页内子标签、字体和 Hex 控件均由分析窗口 UI 线程创建、布局和销毁；后台线程不操作 HWND、GDI、剪贴板或控件内容。批量插入期间的重绘暂停必须在成功、空结果和错误路径上对称恢复，避免窗口残留禁用重绘状态。

## 验收覆盖

实现后的自动与人工验收应覆盖：中文字段、负值、比例换算、单位、重复解释折叠；三种筛选与固定字节顺序；带列头 TSV、摘要、警告和 Hex；A/B 来源及快速换道的选择/滚动保持；格式码 4 的 header-only 查看；最小化、最大化、Hex 展开/收起和 100%–200% DPI 布局；窗口关闭及过期异步任务的 Reader、ListView 和 GDI 生命周期。

发布构建目标为 `Limage_v1.9.15_segy_header_table_x64.exe`，版本标识为 `1.9.15 SEG-Y Header Table`，并继续使用 Windows GUI 子系统。最终测试、PE 校验和 SHA-256 结果由发布流程生成并记录，不在本架构说明中预先声明通过。
