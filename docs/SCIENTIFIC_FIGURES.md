# 叠后单道与科研图

从普通剖面或叠后 Compare 选择“道”，再点图中的一道。Compare 以真实 Inline/Crossline 或现有逻辑道对应取得 A/B；B 缺少对应位置时不会借用 A 的数据。卷头/道头只读取所选头信息来源；单道分析的 A、B 和差值各自可勾选，频谱始终叠加比较，波形可叠加或并列。

“跟随主剖面可见时间窗”“完整记录”和“手动时间窗（绝对秒）”控制实际分析样点。手动输入后用“应用时间窗”提交；报告区分请求与落在真实采样网格上的实取范围。左键在波形或谱内拖框放大，Esc 取消正在进行的框选；滚轮缩放、右键拖动和“复位图内视窗”也只改变图内显示，切换 ms/s 只改变标签。查看“统计与范围”可核对实际样点个数和起止时间。波形统计使用生效的视图数据、且不应用显示增益。差值是时间域 A−B，差值谱是该序列经同样去均值和 Hann 窗后的 FFT 幅度，不是两条幅度谱相减。不能对齐到共同样点时，差值标为不可用。

振幅默认为共同全幅自适应，使用同组有限样点的完整峰值并留边。可选 P1–P99 或手动；P1–P99 取两个有符号分位数中较大的绝对值作为对称半幅，不是“中央 99%”区间。超出视窗的线段只做几何裁剪，不改样值。手动范围与窗口变化无关，显示增益只作用于波形的绘制。A/B/差用实线、短虚线、点划线和来源颜色区分；科研简洁样式使用蓝、橙红、紫及深色图例文字。剖面波形的黑红填充仍表示正负极性。单道新窗口默认 ms、1.8 DIP，使用 Arial 与系统中文回退。默认主刻度按 1、2、2.5、5 × 10 的幂选实际位置，保留手动间隔、等分和 s/ms。波形按真实样点连接，屏幕和 PNG 抗锯齿，SVG 保留矢量文字与路径；非有限样点断开路径。参考 [Nature 轴、字体与图例规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/) 和 [图版及导出指南](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)；这些约定并不声称 GUI 或 SVG 满足该期刊全部投稿规范。

dB 采用同一快照的 A 非直流谱峰作为共同参考；没有正的 A 峰值时使用明确的固定参考 1。隐藏 A、改变波形增益或缩放频率轴不会改变参考。默认显示 `0–min(125 Hz, Nyquist)`，纵轴按该频段的有限谱值完整自适应；125 Hz 不是滤波截止，完整 FFT 仍用于确定主频和参考。相对幅度可以超过 0 dB；例如 B=−A 时差值谱峰约为 +6.02 dB。零能量不会绘制为峰值或底线。手动纵轴只裁剪显示，不写回频谱数据。

“统计与范围”和 Compare 的“查看数据信息”使用同一项 **A/B 信噪比（A 为含噪输入，B 为干净参考）**。仅在真实几何和绝对采样时间匹配且两侧均有限的位置，累计 `Σ B²` 与 `Σ (A−B)²`，再计算 `10 log10(Σ B² / Σ (A−B)²)`；多道不平均逐道 dB。单道使用实际分析窗，区域统计使用当前主图可见范围，局部 B 不补零。参考非零而残差为零是 `+∞`；参考为零而残差非零是 `−∞`；两者均零或没有有效配对时显示 `—` 和原因。旧版以 A 能量为分子的快照不再复用；显示顺序、差值 A−B 与频谱的共同 dB 参考不变。只有 B 确实是干净参考时，才能将结果解释为信噪比。

分析页的“复制当前页”复制图形；卷头、道头和统计页复制文本。“导出图形”可选择屏幕或论文预设并修改宽、高、DPI；支持带像素密度的 PNG 和保留文字及路径的原生 SVG。导出从打开对话框时冻结的有效分析与显示配置生成，不改动 SEG-Y。普通剖面的图像导出与“出”打开的数据导出是不同入口。

已应用的手动绝对时间也是波形图（包括复制和导出）的默认时间轴。真实覆盖之外留白；FFT、统计和差值只用实际取到的样点。有效时间窗完全没有样点时，仍显示所请求的时间轴，并标明未计算频谱，不沿用上一张图。图内缩放仍可单独操作。

## 叠后滤波与数值导出

频谱的“应用到视图”只变更已选 A、B 或两侧的视图设置。算法处理的“逐道时间滤波”则从基准 A 生成 B。两入口支持低通、高通、带通、带阻及兼容带通；Butterworth、Chebyshev I/II、Elliptic 使用同一套 IIR 二阶节设计。双向响应的线性幅度为单向幅度的平方；设计阶数、单程实现阶数、实际边界含义和最少上下文显示在响应预览。频率验证用实际 Nyquist，而非单道谱的 125 Hz 显示上限。参考 [IIR 设计](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.iirfilter.html) 与 [SOS 前后向滤波](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.sosfiltfilt.html)；应用不依赖 Python 或 SciPy。兼容带通保留旧的 Butterworth 高通＋低通默认响应。

“出”直接打开同一个“导出数据”窗口，默认活动面板、当前可见范围和当前有效处理结果；左侧空间、右侧时间，手动模式在原位置启用输入。可选 A、B 或 A−B、基准或有效结果，并核对真实空间/时间与道样点计数。基础 B 仍是加载或生成的 B。当前滤波结果直接按真实索引裁剪，不再滤波；超出有效覆盖时须先生成相应结果。SEG-Y 默认沿用可写的输入采样格式，不支持时用 IEEE 32 位，也可显式选择 IBM 32 位、IEEE 32 位或 IEEE 64 位；选择不影响滤波。可直接复用标准物理道头的 A/B 视图滤波结果保留原文本卷头和已有扩展卷头，不追加扩展块；裁剪或格式变化时按需更新结构字段。其他输出继续记录必要的来源与几何元数据。发布前回读验证几何与采样轴。自动文件名按来源和实际输出重新生成，碰到重名时加序号；用户自定义名不自动改写，替换已有文件须明确确认，输入文件始终受保护。Time Slice 不作为垂直时间剖面导出；频率显示、增益和 wiggle 绘图密度不影响导出的数据。

“导出数据”中，“范围”选择单独在上，常用窗口宽度下空间起止和时间起止在下一行等高对齐。单道窗口的手动分析时间编辑是独立操作：在顶部“分析时间窗”下拉框右侧，输入绝对秒并显式应用；取消不覆盖已生效分析。普通叠后与 Compare 横轴共用同一按字形和 DPI 测量的间距。以刻度末端到数字可见边缘的纵轴视觉间隙为参照；不以外接文字框对齐，轴标题留白独立。

专项测试：`go test ./internal/segyanalysis ./cmd/limage -count=1 -run 'TestTrace'`。Windows 实测应核对三个来源的道号、分析区间、共同参考、正 dB、图例、字体、灰度线型与导出边界。
